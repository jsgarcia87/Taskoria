# Instrucciones de Despliegue (FTP)

La carpeta `ftp_deploy` contiene los archivos listos para subir a tu servidor FTP.

## Pasos para subir:

1.  **Carga los archivos**:
    -   Sube TODO el contenido de la carpeta `ftp_deploy` a la carpeta pública de tu servidor FTP (usualmente llamada `public_html` o `www`).

2.  **Configura la Base de Datos**:
    -   Asegúrate de haber importado el archivo `database.sql` en tu base de datos MySQL (desde phpMyAdmin o similar).
    -   Edita el archivo `api/config.php` en el servidor (o antes de subirlo) con tus credenciales reales:
        ```php
        $db_host = 'tu_host';
        $db_name = 'nombre_base_datos';
        $db_user = 'usuario';
        $db_pass = 'contraseña';
        ```

3.  **IMPORTANTE - Reconstrucción del Frontend**:
    -   **ATENCIÓN**: Debido a limitaciones en este entorno, no pude ejecutar `npm run build` para generar la versión más reciente del frontend con los últimos arreglos (persistencia y tareas).
    -   Los archivos en `ftp_deploy` corresponden a la última versión compilada disponible (`dist`), que podría no tener *algunos* de los cambios recientes de código.
    -   **Para asegurar que tienes la última versión**:
        1.  En tu ordenador local, abre una terminal en la carpeta del proyecto.
        2.  Ejecuta: `npm install` (si no lo has hecho) y luego `npm run build`.
        3.  Esto actualizará la carpeta `dist`.
        4.  Copia el contenido de `dist` a tu servidor FTP, reemplazando los archivos existentes.

4.  **Verificación**:
    -   Accede a tu dominio y verifica que la aplicación carga.
    -   Intenta crear una cuenta y guardar datos para verificar la conexión a la base de datos.
